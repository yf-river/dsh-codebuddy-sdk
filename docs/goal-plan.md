# 当前目标：DSH 管理历史，官方 CodeBuddy Server 执行模型请求

使用 CodeBuddy 账号额度，在 DSH 中完成连续聊天、工具调用、压缩及恢复。以正常工作流程可靠为验收目标，不承诺与官方 DeepSeek 逐字或编程能力等价。

1. 公开认证：通过 Agent SDK 的认证接口沿用当前登录；只在 worker 内存中传递给 Server。不得自行解密或保存 token。
2. 单次请求：隔离子进程加载锁定的官方 `/server` 导出，提交 DSH 当前完整角色历史，结束后清理。
3. 压缩与恢复：DSH 是历史真源，摘要请求单独执行；旧 SDK 会话 ID 不参与恢复，不校验旧历史前缀。
4. 工具与流：公开 MCP 传递 JSON Schema，工具由 DSH 执行；原始模型流组装内容；公开 HTTP 宿主策略限制每请求最多一次出站模型调用。
5. 计量与隔离：读取本次生成的 token、缓存和模型信息，防止累计或缺失值误报；覆盖可控系统提示词，禁用可控规则、记忆及后台执行；SDK 额外恢复请求由出站策略阻止。
6. 验证：单元测试 → 真实 DSH/官方运行时/本地端点 → 日常版本新增最多 8 次 CodeBuddy 验收。旧调用台账不重置；普通请求输出最多 512 token，摘要最多 2048 token，DSH 输入与工具 JSON 最多 64 KiB。

交付包括源码、依赖锁定、配置迁移、中英文说明、复现脚本及脱敏证据。不 commit、push、发布、部署或安装到日常 profile。历史 Goal 0 和旧 Session 验收保留。

日常版本增加结构化错误传递、空回复和拒绝识别、工具整批完整性校验、真实 DSH 上下文超限恢复，以及实际 Web 浏览器验收。最终状态以 [日常版本验收](daily-reliability.md) 为准。
