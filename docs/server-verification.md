# CodeBuddy Server 改造验收

此页保留上一轮 Server 改造与 5 次调用的历史快照。当前日常版本状态见 [日常版本验收](daily-reliability.md)。

本报告对应当前本地 Server 实现；旧 Session 实现的证据保存在 [历史报告](runtime-verification.md)。

## 实现边界

- Node 24.11.1，DSH 0.2.1-rc.3，Agent SDK 0.3.287，CodeBuddy Code 2.172.1。
- 公开认证接口沿用已有登录态；官方 Server 不直接加载 CLI 磁盘凭据。账号门槛检查在私有挂载命名空间中以原 HOME 的写时复制视图进行，取得有效 userinfo，不打印或保存凭据。
- 每次生成由独立 worker 提交 DSH 当前原生角色历史；不修改 SDK transcript，不使用非公开模型网关。
- 公开 MCP 提供原样工具声明；SDK 工具执行被拒绝，实际业务执行由 DSH 完成。
- 公开 `start({ httpProxy })` 宿主策略限制一次出站模型请求，防止 SDK 长度截断恢复追加生成；代理选择沿用进程代理环境。
- 原始模型事件负责文字、推理、工具参数、结束原因及 usage。完整输出后中断 SDK，SDK 自身的取消提示不进入 DSH 回复。

## 验证方法

单元测试覆盖历史角色与工具关系、原生推理字段、重复 ID、并行同参调用、缓存口径、流完整性及出站次数控制。

集成测试使用真实官方运行时和实际 DSH。模型由本地固定 SSE 端点提供；整个进程树处于独立、仅开放 loopback 的网络命名空间，使用虚拟凭据。它证明协议与业务流程，不证明真实模型质量或人民币扣费。

实际 DSH 场景包含自动压缩、通过公共 `/compact` 命令入口连续压缩两次、工具结果裁剪及进程重启续聊。SDK JSON-RPC 没有手动压缩方法，验收临时 profile 使用测试专用控制插件调用公共命令入口；该插件不进入生产 provider 或 npm 发布文件。

原始离线证据位于被 Git 忽略的 `artifacts/sdk-integration/`。早期原接口与可行性证据保留在对应 artifacts 目录和改造前快照中。

## 当前结果

| 检查 | 结果 |
| --- | --- |
| 构建、类型检查、20 项单元检查 | PASS |
| 12 项完整集成检查＋2 项传输专项 | PASS |
| 真实 DSH 自动压缩、连续两次手动压缩、裁剪及压缩后重启 | PASS，模型端点为本地 fixture |
| 真实账号文件工具与回答 | PASS，回答 `842617` |
| 真实账号重启后恢复上下文 | PASS，再次回答 `842617` |
| 真实账号采用压缩摘要后继续生成 | PARTIAL，尚未完成 |

本轮真实请求共 5 次，服务端报告模型为 `deepseek-v4.1-flash-ioa`。首次摘要在 256 token 上限处截断，DSH 拒绝不完整摘要；用户批准后以 2048 token 上限重试，得到完整摘要，但 DSH 认为其估算 482 token 大于原内容的 455 token，未应用。第 5 次验证的是原历史恢复，不能标为已压缩历史的恢复。

这次真实验收的会话过短，不适合证明压缩收益。后续脚本已增加完整文件读取的上下文量；本轮预算已耗尽，没有重跑或扩大调用。真实失败记录保留在 initial-report、summary-retry-report 和 compaction-events 中；实际扣费金额未查询。未来验收脚本保留台账检查，不能用删除台账的方式绕过预算。

已记录的三次正常生成分别为 5990/62、6658/2、6685/2 个输入/输出 token（DSH 记录口径）；两个未采用摘要的 token 明细没有记录为已知值。

## 真实调用预算

用户最初批准新增最多 4 次，后因摘要截断明确调整为最多 5 次 CodeBuddy 尝试。旧 `artifacts/live/budget.json` 保留；本轮台账位于 `artifacts/server-live/budget.json`。普通请求输出最多 256 token，摘要重试上限 2048 token；DSH 消息、系统提示词与工具 JSON 合计最多 64 KiB；失败同样计数。仅在完整离线检查通过后运行，不自动追加预算。

## 剩余差异

CodeBuddy 的用户消息包装、相邻用户消息合并、工具名前缀和部分参数默认值存在。工具 Schema 顶层约束可能由 CLI 重写；DSH 仍验证实际执行参数。文本之外的内容及显式 temperature/stop 不在当前验收范围。每请求独立运行时有启动开销。

实际部署模型、采样和复杂编程能力是否与官方 DeepSeek 一致，需要单独的同题评测；本次流程验收不作此结论。

最终检查与真实调用结果见同目录的 `server-evidence.json`。
